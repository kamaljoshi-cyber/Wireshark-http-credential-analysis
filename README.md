# Wireshark-http-credential-analysis
This project demonstrates how unsecured HTTP traffic can expose sensitive information such as usernames and passwords when transmitted in plaintext over a network. Using Wireshark, network packets were captured and analyzed to identify HTTP login requests and extract credentials from packet data.
